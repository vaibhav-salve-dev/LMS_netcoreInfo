LMS React Dashboard

Design and develop a modern, responsive LMS Student Dashboard using React.js.

Must Have

* Sidebar: Dashboard, My Courses, Assignments, Calendar, Live Classes, Progress, Certificates, Settings
* Header with search, notifications and student profile
* Statistics cards: Enrolled Courses, Completed Courses, Progress, Learning Hours
* Continue Learning section with course cards and progress
* My Courses with status filters
* Upcoming Classes section
* Assignments section with due dates and status
* Learning Progress chart
* Achievements section

Technical Requirements

* React.js
* Reusable components
* React Router
* CSS/Tailwind CSS
* Use mock data/JSON
* Fully responsive for desktop, tablet and mobile

Submission

* GitHub repository
* Live deployed link
* README
* Desktop + mobile screenshots

Deadline: 3–5 working days

Evaluation: UI/UX, React structure, responsiveness, functionality, code quality and creativity.

Note: Do not directly copy an existing LMS. Create your own design and layout.
